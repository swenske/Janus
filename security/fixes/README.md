# Vulnerabilities fixed in Janus's own code

One record per vulnerability, `JANUS-<year>-<nnn>.json`, committed with its
fix. The release that brings it says so in its name, its 🔒 notes and its
`security.json`, and publishes the record's description as a GitHub
security advisory. Format and process: [docs/upstreams.md](../../docs/upstreams.md#januss-own-vulnerabilities).
