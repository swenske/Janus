Packet capture

Captures live traffic on the node and downloads it as a .pcap file (open it in Wireshark or tcpdump). The filter uses tcpdump syntax - ip ip6 arp tcp udp icmp icmp6, [src|dst] host / net / port / portrange, and or not, parentheses. The node automatically leaves out the connection carrying this capture.
