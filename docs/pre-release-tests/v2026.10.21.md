# v2026.10.21 pre-release tests

Tested on 2026-10-21, afternoon. It is
[v2026.10.20-3](v2026.10.20-3.md) with its two fixes and Go's security
fix of the day:

- 🔒 **Go 1.27.3** for every binary - `crypto/x509` refuses a set of
  intermediate certificates known to be compromised,
  [CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809);
- the release's catalog offers the console choice, so the image
  factory builds `"console": "screen"` schematics
  ([#205](https://github.com/swenske/Janus/pull/205));
- a screen-only node shows each line of its console once
  ([#206](https://github.com/swenske/Janus/pull/206)).

HAProxy, the kernels and the extensions' upstreams are v2026.10.19-4's
still. The lab ran v2026.10.20-3, measured again before the update.
A short campaign, as [v2026.10.20-3](v2026.10.20-3.md#verdict)'s report
asked: the update path, the throughput, the failovers, and a
screen-only machine **built by the image factory** this time. The
scenarios: [Lab test scenarios](lab-scenarios.md).

## Verdict

**Ready to promote.** Go 1.27.3 changes nothing measurable on the
nodes - the throughput, the failovers and the update path are the
release's -, the screen-only schematic now builds at the image factory
and boots to a node that registers on its own and shows its console
once, and the console's share does on a real node what the previous
report measured. CI passed at the second attempt of one job, a port
race in the self-update test since fixed
([#213](https://github.com/swenske/Janus/pull/213)).

### A node without a serial console, from the image factory

The same machine as [v2026.10.20-3](v2026.10.20-3.md#a-node-without-a-serial-console)'s,
made by hand on the lab's host - this time from **the image factory's**
`janus-kvm.qcow2` for `{"customization":{"console":"screen"}}`:

- **The factory builds it**: no node runs that schematic, so its image
  isn't pre-built - asked for (the builder's button, `POST
  /api/v1/images/<id>/v2026.10.21/amd64`), it was `building`, then
  ready 42 s later (already under way from the status asked a minute
  before); 53.8 MB, the same size as the default image.
- **Nothing on its serial port**: 266 bytes, the firmware's two lines.
  Read through the Controller alone, as before.
- **Its screen**, once: the first boot's credentials, the motd, janusd's
  log - **each line once** with this release's init
  ([#206](https://github.com/swenske/Janus/pull/206)).
- **Registered on its own**, approved, its log forwarding profile
  applied at admission; v2026.10.21, kernel 7.2.11, `image.json` naming
  the schematic; SELinux enforcing, **0** AVC denials, no oops, CIS
  **33/33**.
- **Under load** (`x-screen-load`, through the Controller's relay):

|---|---|---|---|
| idle | - | 0.02 % | 0.03 % |
| logging every request, the share at its default | 64,532 req/s | **0.02 %** | 28.1 % |
